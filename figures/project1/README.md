# Project 1 figures

These PNG/PDF plots and the GIF are copied from the recorded October experiment outputs. Raw data and statistical conventions are in [the code package](../../code/project1/README.md).

| Files | Content |
| --- | --- |
| gbm_convergence | Coupled strong errors and signed mean bias |
| gbm_distribution | Histograms, exact lognormal density and quantiles |
| nonaffine_convergence | Reference sensitivity and signed payoff differences |
| extension | Moment-balanced update and factor variance |
| cost, error_vs_cost | Recorded integration time at the matched accuracy target |
| convergence_bands | Batch-bootstrap bands and theoretical reference slopes |
| independent_seed_bands | Five independent seeds and fitted-log-error uncertainty |
| paths.gif | Six illustrative log-price/volatility paths |

Full experiments regenerate files under `code/project1/outputs/`; this directory preserves the published figure copies. Runtime measurements vary across machines. GIF sample paths are illustrative, not convergence evidence.
